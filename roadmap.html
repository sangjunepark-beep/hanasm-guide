📘

회의 도구 3종 가동

가이드 v2 + ERP↔가이드 비교 + DB 결정 도구. 5명이 156건 고유 표기를 결정하면 4,491건 전체에 자동 적용.

▼ 자세히
가이드 v2 — 자재·공정 표준 안내서.
ERP↔가이드 비교 — ERP 실제 명칭 vs 가이드 차이 협의 (송기용팀장님 1차안 70건 입력 완료).
DB 결정 도구 — 12개 제품DB(2,502시트·4,491건)에서 추출한 156건 표기에 표준명 결정.
모두 Firestore 실시간 동기화.
📦

박상준 차장 패키징

5명 결정 완료 후 박상준 차장이 패키징. 결정 사전(JSON) + 12개 제품DB + 챗봇 노드 데이터 한 묶음.

▼ 자세히
① 결정 사전 — 156건 표기 × 표준명 매핑.
② 12개 카테고리 제품DB — 원본 + 결정 적용본.
③ 챗봇 노드 데이터 — 통일 명칭 기반 트리(JSON).
이 3종을 압축 한 묶음으로 개발팀에 전달.

개발팀 전달

"이 표준대로 ERP에 적용해주세요" — 코드값(ID)은 그대로, 표시 명칭만 통일.

▼ 자세히
개발팀 인계 시 강조 사항:
· ERP 코드값(ID) 절대 변경 금지 — 옛 주문·매출 이력 보존.
· 표시 명칭만 통일 명칭으로 전환.
· 양방향 매핑 테이블 유지 — 옛 이름 ↔ 새 이름.

회의 도구 데이터를 ERP DB로 이전
ERP가 정답 출처가 됨

현재 회의 도구는 Firestore(임시 저장소)에 결정 데이터를 모으는 단계. 5명 명칭 규정이 끝나면 그 데이터를 통째로 ERP DB로 옮기고, 그 후로는 ERP DB가 모든 시스템의 정답 출처가 됨. Firestore는 회의 단계 도구로만 남거나 폐기.

🛠️

ERP에 표준 명칭 DB 구축

개발팀이 ERP 안에 자재·공정·장비 표준 명칭 관리 DB + 페이지 신설. 회의 도구의 결정 데이터를 이전.

▼ 자세히
· ERP 안에 표준 명칭 마스터 DB 신설 + 관리 페이지 구축.
· Firestore 의 회의 도구 결정 데이터를 ERP DB 로 이관.
· 이전 후엔 ERP DB 가 정답 출처. 구축 범위·기간은 개발팀 검토 후 확정.
🔄

ERP DB → 전 시스템 적용

이전 완료 후엔 ERP DB가 정답. ERP·상품DB·챗봇이 모두 ERP DB의 명칭을 참조.

▼ 자세히
· ERP 화면·서식·공정·재고 → 모두 ERP DB 명칭 사용.
· 신규 명칭 추가·변경은 ERP 관리 페이지에서 직접 (회의 도구 X).
· 양방향 매핑 테이블도 ERP DB 안에 — 옛 이름·새 이름·코드 보존.
📊

전 부서 동일 명칭

웹팀·제품개발·생산·CS 모두 ERP DB 명칭을 봄. 매번 손으로 옮길 일 없음.

▼ 자세히
· ERP 코드값(ID)은 영구 보존 — 옛 주문 검색·매출 이력 유지.
· 표시 명칭은 ERP DB 의 통일 명칭으로 — 화면·문서·이메일 모두 동일.
· 외부 고객 표기(아트지·포멕스 등 옛 이름)도 ERP DB 매핑 테이블로 인식.

전 시스템 완전 자동화
ERP DB 한 곳 수정 = 다 적용

상품DB가 엑셀에서 ERP DB로 이전. 챗봇 노드 데이터도 ERP DB 명칭 변경에 따라 자동 갱신. ERP DB가 단일 정답 출처(SSOT)가 되어 박상준 차장 손 댈 일 없음.

🗄️

상품DB 엑셀 → ERP DB로

12개 카테고리 엑셀 파일이 사라지고, 상품DB가 정식 데이터로 ERP 안에 들어감.

▼ 자세히
· 박상준 차장의 엑셀 12개 → ERP 내부 데이터로 영구 이관.
· ERP DB에서 명칭 변경 → 상품DB 자동 갱신.
· 1,061건 앵커데이터 수작업 영구히 없어짐.
💬

챗봇 노드 자동 갱신

ERP DB 명칭 변경 → 챗봇이 답하는 자재·공정 이름도 자동으로 따라옴. 동의어 사전도 자동 확장.

▼ 자세히
· ERP DB 명칭 변경 → 챗봇 노드 데이터 자동 재생성.
· 옛 이름(포멕스·아트지 등 고객 표현)은 ERP DB 매핑에 영구 보존.
· 새 이름은 표시·응답에 사용.
· 신규 상담 플랫폼(해피톡 대체) 도입 시 동일 흐름 유지.
✨

ERP DB 한 곳 수정 = 다 적용

ERP DB에서 명칭 한 번 바꾸면 ERP 화면·상품DB·챗봇이 모두 자동. 박상준 차장 손 댈 일 0.

▼ 자세히
· ERP DB 가 진정한 단일 정답 출처(SSOT) — 회의 도구는 초기 결정 단계 도구로만 역할.
· 신규 자재 등재 → ERP 관리 페이지에서 직접 → 자동 전 시스템 반영.
· 외주비 0원 · 운영 인력 0 추가.
