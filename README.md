# 하나사인몰 — ERP·가이드 용어 통일 도구

> 자재·공정·장비 명칭을 회의에서 합의하고, 그 결과를 ERP·상품DB·챗봇·CS 매뉴얼에 동기화하기 위한 **단일 진실 소스(SSOT) 도구**.

---

## 개요

하나사인몰의 자재·공정·장비 명칭이 시스템마다 다르게 적혀 있어 운영 효율과 매출에 영향을 주는 문제를 해결하기 위해 만든 **회의용 협업 도구**입니다.

| 시스템 | 명칭 예시 |
|---|---|
| ERP | UV출력기 · 솔벤출력기 · 포맥스3T · 스텐304 |
| 가이드(마케팅) | UV 평판 · 솔벤트 프린터 · 포맥스 (두께 옵션) |
| 상품DB | 혼재 (1,061건) |
| 챗봇 | 미통일 |
| CS 응대 | 고객말+운영자말 혼재 |

본 도구는 **5명 편집자가 동시에 협업하며 통일안을 결정**하고, **5명 동의(전체동의)** 된 항목만을 다운스트림 시스템(ERP·상품DB·챗봇·CS)에 자동 반영하는 SSOT 역할을 합니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 실시간 협업 | 5명(대표·박상준 차장·송기용 팀장·천현정 차장·강두원 팀장) 동시 편집. Firestore 실시간 동기화 |
| 3그룹 분류 | 사용장비(machine) · 공정(stage) · 재질(material) — 각 그룹별 표 |
| 소구분 | 공정 흐름별·자재 계열별 그룹화 (예: "공정 1 · UV인쇄 관련 장비") |
| 1차/최종 협의안 | 회의 전 1차안 + 회의 합의된 최종안 분리 입력 |
| 전체동의 | 5명 합의된 항목 자동 잠금 (다운스트림 반영 대상) |
| 사유 메모 | "왜 이걸로 정했는지" 행별 기록 |
| 다운스트림 추적 | ERP / 상품DB / 챗봇 반영 상태 체크박스 |
| 드래그앤드롭 | 행 순서 · 소구분 순서 · 행 복사(공정 그룹) |
| UNDO | 최근 20건 변경 되돌리기 |
| CSV 출력 | 회의록용(사람 친화) + 주입용(시스템 친화) 2종 |
| 변경 이력 영구 보존 | `erp_term_logs` 컬렉션 |

## 아키텍처 한 장 요약

```
┌──────────────────────────────────────────┐
│  회의 도구 (erp-compare.html + Firestore)│  ← 5명 동시 편집
│  ─ 통일 용어의 SSOT                       │
│  ─ confirmed 상태 = 5명 동의 완료         │
│  ─ 변경 이력 영구 보존                    │
└──────────────────┬───────────────────────┘
                   │ 변경 감지
       ┌───────────┼──────────┬───────────┐
       ▼           ▼          ▼           ▼
   [ERP]      [상품DB]    [챗봇]      [CS 매뉴얼]
   (내부)     (시트)      (내부)      (CS회의록)
```

자세한 통합 방식과 단계별 로드맵은 [`ROADMAP.md`](ROADMAP.md) 참조.

## 호스팅 옵션 (개발팀 결정)

| 옵션 | 장단점 |
|---|---|
| **A. 정적 호스팅 (사내 Nginx)** | 가장 단순. HTML 그대로. 인증은 Nginx Basic Auth |
| **B. 사내 SSO 연동** | 회사 계정 로그인. 기존 사내 시스템과 통합 |
| **C. Firebase Hosting + Auth 강화** | 인프라 변경 최소. Firebase Auth + 도메인 제한 |

자세한 보안·이전 절차는 [`SECURITY.md`](SECURITY.md), [`OPERATIONS.md`](OPERATIONS.md) 참조.
